# 阅读原书网页的标注

用户问网页条目上的标注、或需要按成本/依据理解候选时读取本页；查具体值时从[entry-labels.json](entry-labels.json)按节号和条号取条目，不加载全部条目。这个索引只保存标注，不能代替原书的完整正文与备注。

| 网页标注 | 含义 | 如何解释 |
| --- | --- | --- |
| 性价比极高 / 高 / 一般 | 原作者按收益量级和钱、时间、毅力成本合成的分档 | 只在同一收益口径内比较，不是AI对这个人的人生评分 |
| 证据A / B / C级 | 原作者对来源类型的分级 | 结合条目备注说明具体研究、推论或争议；A不统一等于因果或所有人适用 |
| 换寿命 / 换钱 / 换时间精力 / 换人身自由 | 条目统计或讨论的收益口径 | 不把四类收益换成一个总分，不把“换寿命”当个人延寿承诺 |
| 不花钱 / 花少量钱 / 花不少钱 | 原书钱的成本标签 | 具体费用仍看成本正文；原估计不当现行市场报价 |
| 顺手 / 花几小时 / 每天占时间 | 原书时间成本标签 | “顺手”是粗分档，不表示一定零时间 |
| 不用毅力 / 要一点毅力 / 要很多毅力 | 原书毅力成本标签 | 是作者的概括，个人体验仍由本人反馈，不当人格判断 |
| 争议 / 含待核实 | 原网页按备注与相关字段标记 | 保留具体争议或未核实信息，不因其他标签好看而省略 |

例：第1节第3条的六个标签是“性价比高、证据B级、换寿命、花少量钱、顺手、不用毅力”。它们与原书注释及网页规则一致。B级的理由需同时读备注：烟雾报警器的研究为回顾比较；一氧化碳报警器这一建议是从冬季、家中中毒分布推导，原文未提供其降低死亡率的直接研究。不能把同一卡片的白话框概括成所有措施都经随机试验证明。

紫色说明框对应原书“说人话”，不是另一份AI观点。“来源”折叠区对应原书出处；网页中虚线词语是术语解释，“第X条”可就地打开关联条目，`#`是条目定位链接。PDF可保留标签与框的外观，保留链接和注释说明；网页折叠/筛选逻辑不会因复制样式而在PDF中运行。
