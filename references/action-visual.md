# 行动概览图：内容、设计与交付

只在个人行动方案已经明确时读取。设计参考用于信息呈现；生活建议仍只来自本轮已读取的《高性价比人生指南》，不把设计文章变成新的建议来源。

## 先固定图中的事实

从当前对话和已确认的方案整理这些字段；无需让用户重复回答。公开演示只使用明确提供的虚构设定，不引入其他聊天的个人资料。

| 字段 | 写法 |
| --- | --- |
| 目标 | 用户认可的一件事，通常一句短标题 |
| 当前卡点 | 用户实际表达的困难，用一句话概括，不加心理诊断 |
| 本周行动 | 何时、在哪、做什么、做到怎样算完成；保留用户给出的总时间和频次 |
| 本月回看 | 回看日期/时点、关注哪项真实反馈、怎样决定继续或调整 |
| 本年方向 | 已选的方向与推进条件；未确定则明确写“暂未确定” |
| 条目对应 | 每个独立行动的节号、条号、简短标题、证据等级、固定版本链接 |
| 条件与未知 | 会改变执行的关键前提、尚未确认的事 |
| 版本 | 本轮原书 commit/快照日期，以及方案日期 |

允许删去不影响执行的解释，不能压掉行动、条件或出处。多个行动可分成同一套图：总览标出优先顺序，必要时追加一页详细动作；不为了塞进一张图缩成难以阅读的小字。图中保留完整的已选动作，暂不执行的候选标明“待选”，不画成已安排的任务。

来源映射先于制图。一个行动可能对应多条，例如快走这一活动依据第2节第11条，固定时间和场景依据第4节第1条，把第一步改小依据第4节第9条。“周六晚饭后往返10分钟”是按用户资源做的排期，必须注明为个性化安排，不能声称原书专门推荐这一时长。月度回看及年度分层属于 Skill 的安排方式。研究数字不冒充个人目标、训练上限或效果保证。

图中采用 `第4节·第1条｜明确启动条件` 一类可读简写；配套文字或 SVG/HTML 的链接提供完整原题和固定 commit 的原文地址。只放二维码不能代替可读条号；不能生成未经核验的二维码。沿用原作者证据等级，不另造个人健康分、人生收益分、进度百分比或“已完成”勾号。

## 选择当前能完成的方式

1. **内置图片生成可用：** 使用当前会话暴露的图片工具，提交下面的设计简报与精确文案，交付真实图片。工具可用与否根据本轮工具列表、界面或实际调用结果判断，不根据产品名称推断，不假装调用。使用工具支持的尺寸参数；不把别家参数或模型名硬塞进去。
2. **图片工具不可用或中文/条号修复仍失败：** 直接生成独立 SVG 文件。用真实 `<text>`/`<tspan>` 排中文字，按已确认文案主动换行；提供 `viewBox`、`title`、`desc`、可读字号及可点击出处。使用当前环境已有的中文字体；没有字体渲染能力时明确保留可编辑 SVG，不声称已核验 PNG。用户的文字先做 XML 转义，不拼接成可执行脚本。
3. **已有网页渲染和截图工具且更适合当前版式：** 可以生成独立 HTML/CSS 页面，等待中文字体和内容载入，按海报区域截图成 PNG；页面无导航、表单、侧栏或无用按钮。不要截进浏览器工具栏，不把网页源码当截图交付。文件可以连同可编辑网页一起提供。

优先完成现有工具可做的一条路径；不用为了制图另外注册账号、索取 API key、安装陌生程序或反复切平台。自动图像生成失败后保留简短文字方案，并说明当前限制；有 SVG 能力就继续交付 SVG。既不能生成文件也不能展示图片时，如实给出可复制源码并说明仍未生成图片，不假报完成。

## 让行动一眼能看见

设计目标是可保存的个人行动海报，像经过编辑的生活手册内页。所谓高级感落实到字体、间距、对齐、色彩和内容取舍，不只在提示词里写“高级、精美”。

- **视线顺序：** 先看当前第一步，接着知道为什么这一步适合当前卡点，再看月度/年度安排，最后能查原书出处。主行动占最大的视觉区域；问题是简短导读，图的标题不能抢过执行动作。
- **字体层级：** 通常使用标题、正文、出处三档，靠字号和字重拉开。主要动作要比辅助解释明显更大。中文选清楚的字体，标题可以有少量衬线风格，正文保持易读。长句断行，避免全文粗体或处处变字体。
- **版式：** 统一边距和网格对齐，留白用于区分行动和来源。按内容选择上下递进、左侧大行动加右侧回看等结构，不机械套等大的三张卡片。细分隔线和小编号可以帮助阅读；箭头只用于真实的执行顺序。
- **配色：** 以一套中性色配一个强调色为起点，强调色只突出主行动或当前时点。可选暖白/深墨/森林绿，或浅灰/深蓝/钴蓝；按场景调整，不固定给所有用户同一套配色。保持正文的高对比度。
- **图形：** 一枚与动作有关的简洁原创符号或路线图即可；例如“去5分钟、回5分钟”可以画来回路线。图形必须帮助理解，不生成虚构统计图、无依据仪表盘、无关人物或堆满装饰的励志海报。
- **画布：** 未指定时可从4:5竖版开始，按工具支持选尺寸。主动作在手机缩略图仍能辨认，源图放大后出处能读清；不能靠极小字满足“信息齐全”。内容多则增高画布或拆页。

采用某个作品的字体层级、克制配色和内容排列原则即可，不复制其品牌、标志、图案、具体文案或整套版式。

## 图片生成简报模板

先替换花括号，不把模板标记输出到图里。工具调用中传入完整的精确文案；不要只发“帮我设计高级行动图”。

```text
用途：一张可以保存到手机的个人生活行动概览图。
读者：{当前使用者或明确标记的虚构演示}。
任务：让人先读到本周能执行的动作，再理解当前卡点、月度回看和年度方向，最后能找到原书对应条目。

视觉方向：有编辑感的生活手册海报；清楚的中文字体、强弱分明的字号、统一对齐、充足留白、克制的中性色与一个强调色。主行动是视觉中心。装饰只辅助理解动作，保持信息可读。
画布与阅读：{工具支持的尺寸/比例}；源图清楚，手机缩略图也能读到主动作。所有文字位于画布内，留出边距。
布局：{根据这次内容确定的布局和视线顺序}。

以下为已经确认的内容，不新增任务、改变数字、填补未知或承诺收益。中文逐字准确，允许合理换行。
标题：“{短目标}”
当前卡点：“{已确认卡点}”
本周：“{时间、地点、动作、完成标准}”
本月：“{回看与调整安排}”
本年：“{年度方向及条件/暂未确定}”
出处：“{每个行动对应的第几节·第几条及简短标题}”
条件：“{关键前提与未知}”
说明：“{个性化排期与原文的区别}”
署名：“原文：eternity4719《高性价比人生指南》｜CC BY 4.0｜非官方行动整理”

不要加入更多文案、虚构图表、收益分、已完成勾号、装饰性二维码或品牌标志。完整信息超出版面时扩展布局，不能丢掉关键条件/出处。交付真实图片文件。
```

若使用 SVG/HTML，复用同一份内容和视觉简报，直接编写可编辑文件，按真实字体测量/换行，避免大段文字溢出。链接绑定已经核验的原文地址，不引用未经读取的条目。

## 实际查看后才交付

打开生成结果，检查主动作是否一眼可读、是否还看得出用户的卡点；逐字核对中文、数字、时间总长、频次、条号与行动映射。检查有没有裁切、重叠、来源丢失、虚构完成状态、遗漏关键条件或新增任务。

原尺寸查全文，再缩到手机阅读尺度看主行动；如工具支持可用390像素左右宽的预览作为检查。重点错误先做一次定向修复，只改错字/条号/溢出并保留正确动作；再次出现关键文字错误则改 SVG/HTML，避免无限生成。不能把错误图片当成“只是风格不同”。

交付图片/可编辑文件、实际保存路径或有效下载入口、简短出处链接。图片和文字方案保持相同日期与版本。说明用的是内置生成、SVG，还是网页截图；没实际生成就说未生成。通常一句使用说明即可，不再附长篇设计过程。
